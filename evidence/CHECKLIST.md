# Скриншоты перед отправкой

После локального запуска сохранить в эту папку 4-6 реальных скриншотов:

1. `01-companies-default.png` - `/companies`, видны таблица и общее число 994.
2. `02-companies-search.png` - поиск по части существующего названия.
3. `03-companies-city.png` - фильтр по городу.
4. `04-companies-empty.png` - запрос без результатов.
5. `05-terminal-import.png` - итог `npm run import:pages -- --replace`.
6. `06-terminal-queries.png` - вывод `npm run check:db`.

Не использовать макет или демонстрационные данные: нужны скриншоты реально запущенного проекта с содержимым `data/`.
