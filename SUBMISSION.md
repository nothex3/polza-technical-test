Что реализовано:

- импорт 20 JSON-страниц в PostgreSQL с нормализацией, индексами и идемпотентной дедупликацией;
- 1000 исходных строк, 994 уникальные компании, 6 полных дублей;
- три SQL-запроса из задания;
- серверная страница Next.js `/companies` с поиском, фильтром по городу и пагинацией;
- отдельная загрузка `review.csv` и подробный `ANOMALIES.md`;
- unit-тесты и GitHub Actions CI.

Главный сюрприз в `review.csv`: шесть записей с id `c_900006...c_900011` являются копиями компаний основной выгрузки, но имеют новые id и названия без типографских кавычек. Дополнительно найдены повторы, некорректные рейтинги/отзывы, повреждённая кодировка, сдвиг столбцов, невалидные сайты и телефоны и другие отклонения.
