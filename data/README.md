# Исходные данные

В папке находятся файлы из приложенного `data_pack.zip`:

- `page_001.json` ... `page_020.json`;
- `review.csv`.

Общий объём небольшой, поэтому данные оставлены в репозитории: проект можно проверить без поиска отдельного архива. В JSON находится 1000 исходных строк; после удаления шести полных дублей остаётся 994 компании.
