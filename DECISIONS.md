# Технические решения

## PostgreSQL без ORM

В задании отдельно оцениваются схема, индексы и SQL-запросы. Поэтому используется `pg`: структура таблиц, ограничения, UPSERT и аналитические запросы видны напрямую и не зависят от поведения ORM.

## Дедупликация JSON

Основной идентификатор - `external_id`. Если его нет, ключ строится по более слабым признакам: email/телефон/домен сайта вместе с названием, затем название + город + адрес. SHA-256 ключ хранится в `dedupe_key` под `UNIQUE`, поэтому повторный импорт идемпотентен.

На реальных данных найдено шесть полных повторов между страницами. Все они имеют одинаковый `external_id`, поэтому 1000 исходных строк превращаются в 994 записи.

## Сохранение исходной строки

Каждая компания хранит `raw_data jsonb`, имя файла и номер строки. Это позволяет проверить преобразование, повторно обработать выгрузку с другими правилами и не потерять неизвестные поля.

## Отдельная таблица для review.csv

`review.csv` заранее обозначен как проблемная выгрузка. Он не обновляет `companies`: все 207 строк загружаются в `review_rows`, где рядом лежат исходные, разобранные и нормализованные значения, список проблем и ссылка на совпавшую компанию.

## Поиск замаскированных дублей

Проверки только по `id` недостаточно. Для `review.csv` строится естественный отпечаток без `id`: название без пунктуации, категория, город, адрес, рейтинг, отзывы, сайт и телефон. Так обнаружены шесть записей `c_900006...c_900011`, совпадающих с компаниями основной выгрузки, хотя из названий удалены кавычки и заменены идентификаторы.

## Строгая нормализация

Невалидные значения не исправляются молча. Например, `45.5` не превращается в 45 отзывов, `8 (925) abc-12-34` не становится телефоном, а `нет сайта` и `htp://...` не принимаются за URL. Допустимая мягкая нормализация фиксируется предупреждением, как рейтинг `4,5` или город в другом регистре.

## Серверная страница

`/companies` реализован Server Component. Поиск, фильтр и пагинация выполняются параметризованными SQL-запросами на сервере; браузер получает только текущую страницу данных.
